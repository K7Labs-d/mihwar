# مِحور — منصّة وساطة لتأجير معدات الإنشاءات

موقع بـ HTML/CSS/JS خالص، بلا اعتماديات ولا خطوة بناء. افتح `index.html` في المتصفح مباشرة.

المشروع سطحان يتشاركان بيانات واحدة: **الموقع العام** الذي يراه الزائر، و**لوحة الإدارة** في `admin/`.
ما تعتمده اللوحة يظهر للزائر فوراً، والطلب الذي يرسله الزائر يصل إلى اللوحة — كل ذلك عبر
`localStorage` بلا خادم.

## الملفات

| الملف | الوصف |
|---|---|
| `assets/data.js` | **طبقة البيانات المشتركة** — الكتالوج التجريبي، القراءة والكتابة في التخزين، مسميات الحالات، وكل دوال التنسيق |
| `assets/app.js` | تفاعلات الموقع العام — الكتالوج والفلترة وصفحة المعدة المولّدة وحاسبة التسعير |
| `assets/styles.css` | نظام التصميم بالكامل (متغيّرات CSS، وضع ليلي/نهاري، RTL) |
| `index.html` | الصفحة الرئيسية — هيرو بشريط بحث، فئات بعدّادات حيّة، قائمة معدات مبنية من البيانات، خطوات العمل، أسئلة شائعة |
| `equipment/detail.html` | صفحة معدة **مولّدة** من البيانات عبر `?id=` — تخدم كل معدة لا تملك صفحة مكتوبة يدوياً |
| `equipment/excavator-cat-320.html` | صفحة معدة مكتوبة يدوياً بمحتوى موسّع (معرض متعدد، ملحقات، نطاق نقل) |
| `admin/login.html` | دخول تجريبي محلي |
| `admin/index.html` | مركز العمليات — ما يحتاج تدخلاً، بحث شامل، جداول الطلبات والمعدات والملاك والعملاء والمحادثات |
| `admin/owner.html` · `equipment.html` · `order.html` | ملفات تشغيلية بتبويبات لكل كيان |
| `admin/admin-components.js` | مكونات واجهة مشتركة (ترويسة، تبويبات، خط زمني، شارات، حالات فارغة) |
| `admin/admin.js` · `owner.js` · `equipment.js` · `order.js` | منطق كل شاشة |
| `admin/admin.css` | تصميم اللوحة |

## نموذج العمل — قاعدة تحريرية ملزِمة

**مِحور وسيط ولا يملك المعدات ولا يشغّلها.** أي نصّ يُضاف لهذا الموقع يجب أن يلتزم بالآتي:

**ممنوع** الوعد بـ:
- تأمين على المعدة
- صيانة أو إصلاح أعطال
- توفير معدة بديلة
- ضمان التوفّر أو الجاهزية

**المسموح** وصفه هو ما يفعله الوسيط فعلاً:
- «نتحقق من مستندات المعدة قبل الإدراج» — الاستمارة، الفحص الدوري، إثبات الملكية
- عرض أسعار المالك وشروطه كما وردت
- الربط المباشر بين المستأجر والمالك

العقد يُبرم بين المستأجر والمالك، ومِحور ليس طرفاً فيه. لهذا:
- الزر «أرسل طلب تأجير» لا «احجز» — الطلب ليس حجزاً حتى يؤكده المالك
- تبويب الشروط اسمه «شروط المالك» وينسب الشروط له صراحةً
- قسم ما يشمله السعر عنوانه «ما يحدّده المالك»
- التذييل يحمل تنويهاً بموقف المنصّة في كل صفحة

## طبقة البيانات

مصدر واحد للحقيقة في `assets/data.js`، يقرأ منه السطحان ويكتبان فيه.

```
مفتاح التخزين:  mihwar-data-v4
المفتاح القديم:  mihwar-admin-data-v3  (يُرحَّل تلقائياً عند أول تحميل)
```

الحالة كائن واحد فيه `owners` و`equipment` و`customers` و`orders` و`conversations`. عند غياب
التخزين (تصفّح خاص مثلاً) يعمل السطحان على البذرة في الذاكرة بلا انهيار.

```js
MihwarData.load()                 // الحالة الحالية، مُطبَّعة، أو البذرة
MihwarData.save(state)            // يعيد false إن تعذّر التخزين
MihwarData.reset()                // يعيد البيانات التجريبية
MihwarData.rates(item)            // { day, week, month }
MihwarData.detailPath(item)       // مسار صفحة المعدة على الموقع العام
MihwarData.isListed(item)         // هل تعتمدها الإدارة للعرض؟
```

**نموذج تجريبي — الأسعار استرشادية والسعر النهائي يحدده مالك المعدة.** هذا السطر ظاهر في تذييل
كل صفحة، وكل الأسعار والمواصفات وأسماء المؤسسات بيانات للعرض فقط. العملة ريال سعودي، وضريبة
القيمة المضافة 15%.

### الكتالوج

ست معدات، وكل سعر يُعرض بصيغة **«يبدأ من X ر.س / يوم»**:

| المعدة | الفئة | السعر اليومي | المدينة | المالك |
|---|---|---|---|---|
| بوبكات S650 | تحميل | 600 | الرياض | مؤسسة الراسخ للمقاولات |
| حفّار صغير 5 طن | حفر | 950 | جدة | شركة البناء الحديث |
| قلاب 30 طن | نقل | 1,300 | الدمام | مؤسسة سند للنقل |
| شيول 3 م³ | تحميل | 1,900 | الرياض | مؤسسة الراسخ للمقاولات |
| حفّار جنزير 22 طن | حفر | 3,500 | الرياض | مؤسسة الراسخ للمقاولات |
| رافعة متحركة 50 طن | رفع | 6,500 | جدة | مجموعة الأفق للرافعات |

الفئات الأربع (حفر، تحميل، نقل، رفع) مشتقّة من الكتالوج نفسه، ولكل فئة عدّاد حيّ في الصفحة
الرئيسية. المدن في قوائم الفلترة تُبنى من البيانات كذلك، فإضافة مدينة في اللوحة تظهر في الفلترة.

### التسعير

السعر اليومي هو المصدر، والأسبوع والشهر يُشتقّان منه ما لم يُصرَّح بهما في السجل:

```js
week  = round(day * 6)      // الأسبوع بخصم يعادل 6 أيام
month = round(day * 21.4)   // الشهر يعادل 21.4 يوماً تقريباً
```

أجرة المشغّل ورسوم النقل حقلان لكل معدة (`operatorPerDay` و`transportFlat`). حاسبة التسعير
واحدة تخدم صفحتَي المعدة معاً وتقرأ الأرقام من السجل عبر `data-equipment-id` على النموذج — فلا
سعر مكتوب داخل HTML يمكن أن يتفرّع عن البيانات.

## لوحة الإدارة

الدخول من `admin/login.html` أو من رابط «لوحة الإدارة» في تذييل الموقع.

```
البريد:       admin@mihwar.local     (أو الجوال 0500000000)
كلمة المرور:  Mihwar123
```

**الحماية واجهية بالكامل ولا تصلح لبيئة حقيقية** — كلمة المرور مكتوبة في `admin/admin.js`
ومعروضة على صفحة الدخول. الجلسة في `localStorage` تحت `mihwar-admin-auth` بصلاحية اثنتي عشرة
ساعة؛ وُضعت هناك لا في `sessionStorage` كي لا يُطرد المستخدم عند فتح أي سجل في تبويب جديد. كل
صفحة إدارة تحمل حارساً مضمّناً في `<head>` يخفي الجسم حتى يتم التحقق، فلا يومض المحتوى قبل
التحويل.

ما تفعله اللوحة فعلاً: إضافة وتعديل وحذف الملاك والمعدات والطلبات، تغيير حالات الطلب عبر مسار
مسموح، تأكيد الدفع، تسجيل الملاحظات، إرسال رسائل إدارية، وبحث شامل عبر الكيانات الأربعة. الحذف
يرفض ترك سجلات يتيمة، فلا يُحذف مالك مرتبط بمعدات أو طلبات ولا معدة مرتبطة بطلبات.

### الدورة الكاملة

1. الزائر يفتح صفحة معدة ويملأ لوحة الطلب (الاسم والجوال والتاريخ والمدة).
2. الإرسال يُنشئ عميلاً وطلباً ومحادثة في التخزين المشترك.
3. الطلب يظهر في «يحتاج انتباهك» على لوحة الإدارة برقمه، ومعه رسالة غير مقروءة.
4. المشغّل يفتح ملف الطلب فيقبله أو يرفضه ويتابع حالته حتى الإغلاق.

بالاتجاه المعاكس: إيقاف عرض معدة أو حذفها من اللوحة يزيلها من الكتالوج العام فوراً، وتعديل
سعرها يظهر في البطاقة وفي الحاسبة.

للعودة إلى نقطة البداية: **الإعدادات ← إعادة البيانات التجريبية**.

## النسخة السحابية — ملف واحد

`tools/build-cloud-bundle.py` يجمع الصفحات الثماني وأنماطها وسكربتاتها وخطوطها في
`mihwar-cloud.html` واحد قائم بذاته، صالح للنشر على أي مضيف ثابت أو للفتح مباشرة بلا خادم.

```bash
python3 tools/build-cloud-bundle.py            # ينتج mihwar-cloud.html في جذر المستودع
python3 tools/build-cloud-bundle.py out.html   # أو إلى مسار تختاره
```

كيف يعمل: جسم كل صفحة يُخزَّن في `<template data-route="…">`، وكل ملف JS يُلَفّ في دالة
تستقبل `location` و`history` و`localStorage` كوسائط تُظلّل العوامّ الأصلية. الموجّه يملأ
`document.body` بقالب الوجهة ثم يشغّل سكربتات تلك الصفحة بموقع وهمي يحمل مسارها
و`?id=` و`#tab` — فيعمل `location.search` و`location.replace('login.html')` و
`history.replaceState` كما لو كانت صفحات منفصلة. الروابط الداخلية تُعترض عند النقر وتُحلّ
نسبياً مقابل المسار الحالي، فتشتغل حتى الروابط التي تولّدها اللوحة وقت التشغيل.

ما يتغيّر عن النسخة متعدّدة الملفات:

- **الخطوط مضمّنة** بصيغة data URI بدل Google Fonts — لا طلبات شبكة إطلاقاً.
- **لا مسار في شريط العنوان**؛ التنقّل في الذاكرة، وزرّ رجوع المتصفح لا يتراجع بين الصفحات.
- **التخزين يتراجع إلى الذاكرة** إن مُنع `localStorage` (إطار معزول مثلاً)، فتبقى الجلسة
  والطلبات عاملة داخل التبويب دون أن تُحفظ بعد إغلاقه.

`.cache/fonts/` يخزّن ملفات الخطوط المنزَّلة كي لا يتكرّر التنزيل، وهو خارج التتبّع.

## ملاحظات تقنية

- **الخطوط:** Tajawal (عناوين) و Cairo (نصوص) عبر Google Fonts — تحتاج اتصالاً بالإنترنت.
- **الوضع الليلي:** تفضيل النظام هو الإشارة الافتراضية، وسمة `data-theme` على `<html>` تتغلّب عليه. الاختيار يُحفظ في `localStorage` تحت `mihwar-theme`، ويُطبَّق بسكربت مضمّن في `<head>` قبل الرسم لمنع وميض الوضع الخاطئ.
- **RTL:** خصائص منطقية (`margin-inline`, `inset-inline-start`) بدل `left/right`، وأسهم التبويبات معكوسة لتطابق اتجاه القراءة — في الموقع العام وفي تبويبات ملفات الإدارة معاً.
- **الرسوم:** كل رسوم المعدات SVG مضمّن عبر `<symbol>` و `<use>` — لا صور خارجية.
- **لا backend:** لا شبكة ولا قاعدة بيانات؛ كل شيء في `localStorage` على جهاز الزائر.
- **التهريب:** كل نصّ يمرّ عبر `escapeHTML` قبل الحقن، وكل رابط عبر `safeUrl` التي تمنع المخططات القابلة للتنفيذ مثل `javascript:`.

### قواعد العرض

**التقويم ميلادي والأرقام لاتينية.** كل التنسيق يمرّ عبر `assets/data.js` على المحلّية:

```js
var LOCALE = 'ar-SA-u-ca-gregory-nu-latn';
```

كلا المُعدِّلين ضروري: `-nu-latn` وحدها تُبقي الأرقام لاتينية لكنها تترك التقويم هجرياً، فيصير
`2026-08-01` معروضاً «18 صفر 1448 هـ» في المتصفحات بينما المُدخل ميلادي وحقول `<input type="date">`
ميلادية. و`-ca-gregory` يثبّت التقويم.

فاصل الآلاف `,` والفاصلة العشرية `.`، ولا تُستخدم الأرقام الهندية (U+0660–U+0669) ولا الفواصل
العربية (U+066B و U+066C) في أي نصّ.

**العدد يُطابق معدوده.** «7 يوم» خطأ. استخدم `MihwarData.countLabel` التي تتولى المفرد والمثنّى
وجمع القلة (3–10) والمفرد المنصوب (11 فصاعداً):

```js
MihwarData.countLabel(7, { one: 'يوم واحد', two: 'يومان', few: 'أيام', many: 'يوماً' });
// "7 أيام"
```

**لا حالة تظهر بمفتاحها الإنجليزي.** كل مسميات الحالات في `assets/data.js` وحده
(`ORDER_STATUS_LABELS`، `EQUIPMENT_STATUS_LABELS`، `RECORD_STATUS_LABELS` …). لأي حالة عامة على
حجز أو سجل صيانة أو عملية مالية استخدم `MihwarAdmin.recordStatusLabel(status)`.

### التحقق بعد أي تعديل

فحص المصدر من الأرقام الهندية:

```bash
python3 - <<'PY'
import os
bad = {chr(c) for c in range(0x0660, 0x066D)}
hits = [(os.path.join(r,f), ch)
        for r,_,fs in os.walk('.') for f in fs
        for ch in open(os.path.join(r,f), encoding='utf-8').read() if ch in bad]
print("المخالفات:", len(hits))
PY
```

هذا الفحص يغطّي المصدر فقط. أما ما تولّده `Intl` وقت التشغيل فلا يظهر فيه — ولهذا مرّت مشكلة
التقويم الهجري سابقاً. للتحقق من الناتج الفعلي افتح الصفحة وشغّل في طرفية المتصفح:

```js
// المحارف مكتوبة بالهروب كي لا يلتقط فحص المصدر أعلاه هذا السطر نفسه
[...new Set(document.body.innerText.match(/[\u0660-\u0669\u066B\u066C]/g) || [])]  // []
new Intl.DateTimeFormat(MihwarData.LOCALE).resolvedOptions().calendar             // "gregory"
```

### مآزق تستحق الانتباه عند التعديل

`hidden` خاصية معرّفة على `HTMLElement` وليست على `SVGElement`. إسناد `el.hidden = true`
لعنصر SVG ينشئ خاصية زائدة على الكائن دون أن يمسّ السمة، فلا يتأثر العرض إطلاقاً.
لهذا يستخدم تبديل صور المعرض `toggleAttribute('hidden', bool)` المتاح على `Element`.

إيقاف عرض معدة يحفظ حالتها في `previousStatus` ليستعيدها زر التفعيل. احرص أن تُسنَد إليه الحالة
**السابقة** لا الجديدة، وإلّا قفزت معدة «بانتظار المراجعة» إلى العرض بضغطة واحدة متجاوزةً
المراجعة. المنطق نفسه مطبَّق في جدول اللوحة وفي صفحة المعدة، فأي تغيير يجب أن يطالهما معاً.
