# مِحور — منصّة وساطة لتأجير معدات الإنشاءات

موقع بـ HTML/CSS/JS خالص، بلا اعتماديات ولا خطوة بناء. افتح `index.html` في المتصفح مباشرة.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية — هيرو بشريط بحث، فئات، قائمة معدات بفلترة حيّة، خطوات العمل، لماذا مِحور، أسئلة شائعة |
| `equipment/excavator-cat-320.html` | صفحة معدة كاملة — معرض، بطاقة المورّد، تبويبات، جدول مواصفات، لوحة طلب بحاسبة تسعير حيّة |
| `assets/styles.css` | نظام التصميم بالكامل (متغيّرات CSS، وضع ليلي/نهاري، RTL) |
| `assets/app.js` | كل التفاعلات — ملف واحد يخدم الصفحتين، وكل وحدة تتحقق من وجود عناصرها قبل الربط |

## نموذج العمل — قاعدة تحريرية ملزِمة

**مِحور وسيط ولا يملك المعدات ولا يشغّلها.** أي نصّ يُضاف لهذا الموقع يجب أن يلتزم بالآتي:

**ممنوع** الوعد بـ:
- تأمين على المعدة
- صيانة أو إصلاح أعطال
- توفير معدة بديلة
- ضمان التوفّر أو الجاهزية

**المسموح** وصفه هو ما يفعله الوسيط فعلاً:
- «نتحقق من مستندات المعدة قبل الإدراج» — الاستمارة، الفحص الدوري، إثبات الملكية
- عرض أسعار المالك وشروطه كما وردت
- الربط المباشر بين المستأجر والمالك

العقد يُبرم بين المستأجر والمالك، ومِحور ليس طرفاً فيه. لهذا:
- الزر «أرسل طلب تأجير» لا «احجز» — الطلب ليس حجزاً حتى يؤكده المالك
- تبويب الشروط اسمه «شروط المالك» وينسب الشروط له صراحةً
- قسم ما يشمله السعر عنوانه «ما يحدّده المالك»
- التذييل يحمل تنويهاً بموقف المنصّة في كل صفحة

## البيانات

**نموذج تجريبي — الأسعار استرشادية والسعر النهائي يحدده مالك المعدة.** هذا السطر ظاهر في تذييل كل صفحة، وكل الأسعار والمواصفات وأسماء المؤسسات بيانات للعرض فقط. العملة ريال سعودي، وضريبة القيمة المضافة 15%.

### الكتالوج

ست معدات، وكل سعر يُعرض بصيغة **«يبدأ من X ر.س / يوم»**:

| المعدة | الفئة | السعر اليومي | المدينة |
|---|---|---|---|
| بوبكات S650 | تحميل | 600 | الرياض |
| حفّار صغير 5 طن | حفر | 950 | جدة |
| قلاب 30 طن | نقل | 1,300 | الدمام |
| شيول 3 م³ | تحميل | 1,900 | الرياض |
| حفّار جنزير 22 طن | حفر | 3,500 | الرياض |
| رافعة متحركة 50 طن | رفع | 6,500 | جدة |

الفئات الأربع (حفر، تحميل، نقل، رفع) مشتقّة من الكتالوج نفسه، فلكل فئة معدة واحدة على الأقل ولا توجد فئة فارغة.

صفحة التفاصيل الوحيدة هي **حفّار جنزير 22 طن** (كاتربيلر 320)، وأسعارها في `initCalculator` داخل `assets/app.js`:

```js
var RATES = { day: 3500, week: 21000, month: 75000 };  // للوحدة الواحدة
var OPERATOR_PER_DAY = 420;
var TRANSPORT_FLAT = 900;
var VAT = 0.15;
```

الأسبوع بخصم يعادل 6 أيام، والشهر يعادل 21.4 يوماً تقريباً. عند تغيير السعر اليومي حدّث الثلاثة معاً وحدّث بطاقة المعدة في `index.html` كي تبقى متطابقة.

**ملاحظة تحريرية:** كل الأرقام في الموقع لاتينية (22 طن، 3 م³، 3,500 ر.س) — بما فيها ما تولّده حاسبة التسعير وقت التشغيل عبر `Intl.NumberFormat('ar-SA-u-nu-latn')` في `assets/app.js`. فاصل الآلاف `,` والفاصلة العشرية `.`، ولا تُستخدم الأرقام الهندية (U+0660–U+0669) ولا الفواصل العربية (U+066B و U+066C) في أي نصّ.

للتحقق من ذلك آلياً بعد أي تعديل:

```bash
python3 - <<'PY'
import os
bad = {chr(c) for c in range(0x0660, 0x066D)}
hits = [(os.path.join(r,f), ch)
        for r,_,fs in os.walk('.') for f in fs
        for ch in open(os.path.join(r,f), encoding='utf-8').read() if ch in bad]
print("المخالفات:", len(hits))
PY
```

## ملاحظات تقنية

- **الخطوط:** Tajawal (عناوين) و Cairo (نصوص) عبر Google Fonts — تحتاج اتصالاً بالإنترنت.
- **الوضع الليلي:** تفضيل النظام هو الإشارة الافتراضية، وسمة `data-theme` على `<html>` تتغلّب عليه. الاختيار يُحفظ في `localStorage` تحت `mihwar-theme`، ويُطبَّق بسكربت مضمّن في `<head>` قبل الرسم لمنع وميض الوضع الخاطئ.
- **RTL:** خصائص منطقية (`margin-inline`, `inset-inline-start`) بدل `left/right`، وأسهم التبويبات معكوسة لتطابق اتجاه القراءة.
- **الرسوم:** كل رسوم المعدات SVG مضمّن عبر `<symbol>` و `<use>` — لا صور خارجية.
- **لا backend:** النماذج تعمل على مستوى الواجهة فقط؛ إرسال الطلب يعرض رسالة تأكيد ولا يرسل شيئاً.

### مأزق يستحق الانتباه عند التعديل

`hidden` خاصية معرّفة على `HTMLElement` وليست على `SVGElement`. إسناد `el.hidden = true`
لعنصر SVG ينشئ خاصية زائدة على الكائن دون أن يمسّ السمة، فلا يتأثر العرض إطلاقاً.
لهذا يستخدم تبديل صور المعرض `toggleAttribute('hidden', bool)` المتاح على `Element`.
