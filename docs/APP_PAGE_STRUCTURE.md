# هيكل صفحات تطبيق محور

نطاق هذه المرحلة: واجهة قابلة للتصفح لخريطة المنتج المعتمدة، بتاريخ 2026-09-26. المرجع هو [Master Product Blueprint](MIHWAR_MASTER_PRODUCT_BLUEPRINT.md)، والحالة التنفيذية تحددها المسارات والكود الحاليان. إضافة صفحة لا تعني إنجاز الكيان أو خدمته الخلفية.

## ما يبقى فعليًا

تظل الحسابات والجلسات وطلبات العميل ومحادثات الإدارة وتسجيل واعتماد المؤجر وملف المؤجر وإدارة معداته وظائف محفوظة على الخادم كما كانت. تستخدم الصفحات الحالية واجهاتها وصلاحياتها دون إعادة بناء. لا تضيف هذه المرحلة Backend أو جداول أو API أو بيانات منتج أو صلاحيات جديدة.

لم تُدمج خدمة سوق المعدات العامة بهذه المرحلة. صفحة السوق الجديدة وحدها لا تعني إتاحة معدات الملاك للعموم، ولا تعيد استخدام API معدات المالك الخاصة لعرض بيانات عامة. لم تُنفذ عمليات إرسال عروض أو اختيار عرض أو حجز أو دفع أو تنفيذ أو رفع مستندات.

أسماء الصفحات لا تعتمد حالات عمل أو سياسات مالية. لا تعني كلمة «إتمام» حدوث إتمام فعلي، ولا تعرض صفحات المدفوعات رصيدًا أو عمولة صفرية بوصفها نتيجة محاسبية. جميع هذه الخدمات قيد الإكمال حتى تُبنى على كياناتها الحقيقية.

## التنقل وحدود الواجهة

- يجمع دليل الصفحات المسارات والأسماء وروابط الأقسام؛ تدعم روابط hash الفتح المباشر والتحديث ورجوع المتصفح وتقدمه. يظل المحور والعجلة والهوية العربية وRTL متاحين، مع مسار رجوع وروابط بين الصفحات المرتبطة.
- تستخدم الصفحات الجديدة الحالات الفارغة وعبارة «الميزة قيد الإكمال» بدل بيانات أو نشاط أو نجاح مصطنع. لا تُستخدم Mock APIs أو `localStorage` لإيهام المستخدم بحفظ عملية.
- تظل بيانات العميل والمالك والإدارة الحالية محمية بخادمها. واجهة قسم إداري فارغ ليست صلاحية إدارية ولا تمنح الوصول إلى بيانات أو أفعال محمية. صلاحيتا استقبال الطلبات ومراجعة المؤجرين الموجودتان مستقلتان؛ لا توسع إحداهما ضمنيًا إلى إدارة المعدات أو الأموال أو النزاعات.
- الصفحات الجديدة لا تضيف حقولًا مالية أو أزرار اعتماد/دفع/إرسال تنفّذ نجاحًا محليًا. عند غياب خدمة فعلية يقتصر الإجراء على التنقل أو توضيح عدم التوفر؛ أفعال التسجيل والمراجعة والمعدات الحالية تبقى مرتبطة بخادمها.

## التحقق والمرحلة التالية

قبول هيكل الصفحات يتطلب فتح المسارات الأربعين، وسلامة روابطها وعودتها، وعدم تجاوز عرض الجوال، والحفاظ على وظائف الحسابات والطلبات والمراجعة والمعدات، ونجاح `npm run check`. نجاح هذه الفحوص يثبت الواجهة وما تغطيه الاختبارات الحالية، ولا يثبت دورة حجز أو دفع غير منفذة.

تبقى **NEXT: Equipment Marketplace** كما في المرجع المعتمد. بعد ربط التصفح العام بمعدات حقيقية ومراجعة خصوصية API واختبار انعكاس تعديل المعدة وأرشفتها، يُستكمل ترتيب الاعتماديات المعتمد. لا تُرقّى أي مرحلة خلفية إلى DONE لمجرد وجود صفحتها.
