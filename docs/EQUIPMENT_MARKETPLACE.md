# Equipment Marketplace

المرجع: `MIHWAR_MASTER_PRODUCT_BLUEPRINT.docx`. هذه المرحلة تلي Lessor Foundation + Equipment Core، وتضيف القراءة العامة للمعدات الموجودة دون جداول أو خدمات أو مصادقة موازية.

## الرحلة

الرئيسية أو التنقل → `/#marketplace` → بحث وتصفية → `/#marketplace/<equipment-id>` → العودة إلى النتائج بالفلاتر نفسها. تعمل دون تسجيل الدخول. تبقى خيارات البحث في الرابط بعد التحديث ورجوع المتصفح. إدارة المعدات الخاصة في `/#equipment` تبقى محمية بالجلسة وأهلية المؤجر.

الواجهة تعرض أسعار الساعة واليوم المتاحة، التصنيف، الموقع، الوصف، خيار المشغل، التوفر، اسم المؤجر ونوعه فقط. لا توجد صور افتراضية أو تقييمات أو أعداد مخترعة. عدم وجود معدات يعرض حالة فارغة حقيقية. التحميل والخطأ وعدم العثور على المعدة وإعادة المحاولة حالات مستقلة؛ لا تُعرض النتائج القديمة عند تغير البحث.

## API

- `GET /api/marketplace/equipment`: `{ equipment, total, page, pageSize: 20 }`.
- `GET /api/marketplace/equipment/:id`: `{ equipment }`، أو `404` عند غياب المعدة أو زوال أهلية نشرها.
- الكتابة إلى المسارات العامة مرفوضة بـ`405`. تُدار المعدات عبر API المالك الموجود فقط.
- مفاتيح الاستعلام: `q`, `category`, `location`, `operatorMode`, `availability`, `rateUnit`, `minRateHalalas`, `maxRateHalalas`, `sort`, `page`. البحث النصي حرفي في الاسم والوصف والموقع، وليس بحث مسافة أو Matching.
- السعر بالهللة الصحيحة، والوحدة `day` افتراضيًا أو `hour`، والترتيب `newest` أو `price_asc` أو `price_desc`. تصفية السعر وترتيبه يستبعدان المعدات التي ليس لها سعر بالوحدة المختارة؛ غياب السعر ليس صفرًا.
- المفاتيح المجهولة أو المتكررة والقيم غير الصحيحة مرفوضة. مدخلات SQL ممررة بمعاملات، ورموز `%`, `_`, `\` حرفية في البحث. العدد والنتائج من قراءة SQLite متسقة واحدة.

## أهلية النشر والخصوصية

يشترط لكل نتيجة وتفاصيل: `equipment.status = active` و`lessor_profiles.status = approved` وطلب اعتماد `approved` مرتبط بالحساب نفسه. المعدات النشطة غير المتاحة تظهر بحالتها الحقيقية، ويمكن تصفيتها. الأرشفة أو زوال الاعتماد يخفي المعدة من القراءة العامة التالية.

الاستجابة قائمة حقول صريحة. لا تنشر معرف المالك أو ملفه أو طلب اعتماده، البريد أو الهاتف أو الهوية، المراجع أو القرار، رقم النسخة أو بيانات منع التكرار. القراءة العامة تستخدم اتصال SQLite الموجود؛ لا تغيير في نموذج الجلسات والصلاحيات أو البيانات السابقة.

## الحدود والخطوة التالية

التوفر يدوي وليس تقويم حجز، ولا يؤكد موعدًا. الحجز المباشر والعروض والدفع والتنفيذ والمرفقات خارج المرحلة. رابط «نشر طلب احتياج» يفتح دورة الطلب الحالية المستقلة؛ لا ينشئ حجزًا ولا يربط الطلب تلقائيًا بالمعدة.

المرحلة التالية وفق الاعتماديات: **Structured Request**، ثم Matching ثم Offers. لا يبدأ نظام العروض قبل تكييف الطلب للتصنيف والموقع ومدة الاحتياج بما يتوافق مع المعدات.
